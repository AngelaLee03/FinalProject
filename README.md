## Game Description:

*Honeyburrow: Bunny Trail* is a mobile puzzle game where players must draw a path to guide their character safely to the goal. Each level presents a unique challenge filled with obstacles, hazards, and enemies that require careful planning and strategy to overcome.

The core gameplay revolves around creating efficient and safe routes in real time. Players must analyze enemy movement, avoid obstacles, and adapt their path to changing conditions. Rather than relying on their reflexes alone, the game emphasizes problem-solving, strategy, and decision-making.

As players progress, levels introduce increasingly complex mechanics such as moving hazards, multiple routes, and more advanced enemy behaviors. The ultimate goal is to reach the end point without being caught by an enemy or blocked by the layout/obstacles, advancing through progressively more challenging stages.

## Features & Class Concepts:

This project incorporates various concepts learned in class as well as additional game aspects, including:

- Player-created pathfinding mechanics
- Enemy AI behaviors (patrolling, attacking and blocking paths)
- Collision detection and obstacle interaction
- Touch-based input for mobile gameplay
- Level progression and increasing difficulty
- Life system with checkpoints
- UI systems (main menu, pause menu, level complete, game over, ending screen)
- Audio system with sound effects for gameplay and UI
